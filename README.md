## What I do
 
I build and maintain web applications in PHP, covering the back end, the database and the front end. Day to day, that includes:
 
**Back end**
- Building REST APIs
- Authentication and role-based permissions
- Admin panels and back-office tools
- Integrating third-party services (payments, email and more)
**Database**
- Schema design and migrations
- Query and index optimization in MySQL
**Infrastructure and workflow**
- Working with Linux servers (Nginx/Apache, SSH)
- Deployment and CI/CD
- Containerized environments with Docker
- Automated tests with PHPUnit / Pest
- Git-based workflows, mostly from the terminal, with Claude as a coding assistant
**Front end**
- Responsive interfaces with Bootstrap and Tailwind CSS, on top of HTML, CSS and JavaScript
